# Simple Calculator and Unit Converter

This is a simple console calculator built in C#.
The user can perform basic math operations with just 2 numbers only.
The user can also perform basic unit conversions.

The supported unit conversions are:

1. The conversion of Kilometres to Miles and Vice Versa.
2. The conversion of Degrees Celcius to Fahrenheit and Vice Versa.
3. The conversion of GHS to USD using the rate the user types in.

## Technology Stack

* C#

## How to run the application

Clone the repository:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd <YOUR_PROJECT_DIRECTORY>
```
Once in the project folder, open terminal and navigate to project root and run:

```bash
dotnet run
```
Or 

Alternatively you can click the green play icon at the top of the screen in Visual Studio or any IDE / code editor you might be using.
